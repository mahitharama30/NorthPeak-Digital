# Changelog

## Website Optimizations

### 1. Responsive Design
- Optimized the website layout for mobile (360px), tablet (768px), and desktop (1440px).
- **Benefit:** Provides a consistent and user-friendly experience across different screen sizes.

### 2. Semantic HTML
- Used semantic HTML5 elements such as `<header>`, `<nav>`, `<section>`, `<main>`, `<footer>`, and `<form>`.
- **Benefit:** Improves accessibility, SEO, and code readability.

### 3. Contact Form Validation
- Implemented JavaScript validation for required fields and email format.
- **Benefit:** Prevents invalid form submissions and improves user experience.

### 4. Smooth Scrolling Navigation
- Added smooth scrolling between sections using JavaScript.
- **Benefit:** Creates a better and more professional navigation experience.

### 5. Interactive UI
- Added hover effects, transitions, and animations for buttons and service cards.
- **Benefit:** Makes the website more engaging and visually appealing.

### 6. Clean CSS Structure
- Organized styles using reusable classes and responsive media queries.
- **Benefit:** Improves maintainability and scalability of the code.

### 7. Performance Improvements
- Optimized layout, minimized unnecessary styling, and maintained a lightweight structure.
- **Benefit:** Helps achieve better Lighthouse Performance and Accessibility scores.

### 8. Accessibility Improvements
- Used proper heading hierarchy, readable font sizes, and sufficient colour contrast.
- **Benefit:** Makes the website easier to use for all users and improves accessibility scores.
