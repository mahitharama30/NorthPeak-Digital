# NorthPeak Digital

A modern, responsive one-page agency website developed as part of the **Digital Heroes Web Development Internship Qualification Task**.

## 🚀 Project Overview

NorthPeak Digital is a fictional digital agency website designed to showcase web development services. The website is built using HTML, CSS, and JavaScript with a focus on responsive design, accessibility, and clean user experience.

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Modern hero section with Call-to-Action
- Services section with six service cards
- Client testimonials
- Pricing section with three plans
- Contact form with JavaScript validation
- Smooth scrolling navigation
- Interactive animations and hover effects
- Clean and semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
